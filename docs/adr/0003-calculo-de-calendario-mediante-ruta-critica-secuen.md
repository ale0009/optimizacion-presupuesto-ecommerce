# ADR-0003: Cálculo de calendario mediante ruta crítica secuencial de fases

- **Estado:** Aceptado
- **Fecha:** 2026-11-09
- **Proyecto:** Optimización de presupuesto para e-commerce

## Contexto

Se requiere vincular la capacidad laboral y la duración mínima viable del proyecto para asegurar calidad.

## Decisión

Definir una secuencia lineal de siete fases cuya suma determina la duración mínima del proyecto que rige la capacidad requerida.

## Consecuencias

Garantiza coherencia entre las semanas mínimas de desarrollo y los límites de horas laborales en una formulación lineal eficiente.
